例題14（円形の土地の周りの道）

半径 r m の円形の土地の周りに幅 a m の道がある。道の中央を通る円周の長さを ℓ m、道の面積を S m² とするとき、S = aℓ となることを証明しなさい。

なぜ「縦 a × 横 ℓ」になるの？

  1. 1. 道を切って広げると「台形」になる
    外側の周は内側の周より長いため、道を切ってまっすぐ広げると、上底 2πr、下底 2π(r+a)、高さ a の台形になります。
  2. 2. 中央の線 ℓ は台形の「真ん中の横線」
    道の中央を通る線 ℓ は、上底と下底のちょうど平均の長さ（2πr + πa）になっています。
  3. 3. 台形の端を移動すると「長方形」に！
    はみ出た直角三角形を切り取って反対側へ移動すると、縦が道幅 a、横が中央の線の長さ ℓ の長方形にぴったり変形できます。

例題14の解答
【1】道の中央を通る円周の長さ ℓ を表す
道の中央を通る円の半径は r + ½a だから、
ℓ = 2π(r + ½a) = 2πr + πa ……①
【2】道の面積 S を表す（外側の円 − 内側の円）
外側の円の半径は r + a だから、
S = π(r + a)² − πr²
= π(r² + 2ar + a²) − πr²
= 2πar + πa²
= a(2πr + πa) ……②
【3】①、②より結論を導く
①を②に代入すると、 S = aℓ
【1】道の中央を通る正方形の周の長さ ℓ を表す
道の中央を通る正方形の1辺の長さは p + a だから、
ℓ = 4(p + a) ……①
【2】道の面積 S を表す（外側の正方形 − 内側の正方形）
外側の正方形の1辺の長さは p + 2a だから、
S = (p + 2a)² − p²
= (p² + 4ap + 4a²) − p²
= 4ap + 4a²
= a × 4(p + a) ……②
【3】①、②より結論を導く
①を②に代入すると、 S = aℓ
